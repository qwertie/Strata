# contracts/

What the C++ engine, the Python programs and the app must agree on, written once: the engine protocol and the model
family catalog. It depends on nothing.

**A2** adds the family catalog (read by `strata_common`); **A5** adds the protocol specification.

See [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md) for the layers and [docs/REFACTOR_PLAN.md](../docs/REFACTOR_PLAN.md)
for the steps.
